A parametric space of nail geometries for press-on design

In this project, we will begin by asking the question “how diverse are the shapes of people’s nails?”, which we will answer by scanning a set of volunteers and performing existing dimensionality reduction techniques to represent each nail as a set of parameters. We will continue by exploring the design of prosthetic “press-on” nails, designing a conversion table between the learned parameters and the parameters needed for manufacture, and culminating with a user study with volunteer participants in which press-on nails are manufactured and tested for comfort and fit.

The Anti-Ghost-Gun certificate

Much like conventional 2D printers contain software that detects the intention to print counterfeit currency, we wish to design an algorithm that can be embedded in 3D printers to detect and stop the 3D printing of firearms. In particular, we will work on designing new detectors and adversaries for our open-source benchmark.

Foveated geometry

In collaboration with Prof. Niall Williams

“Foveated rendering” is a well-studied optimization technique that reduces the workload of a graphics processor by rendering high pixel detail only where a user is looking. It is particularly common in lightweight, realtime applications like Virtual Reality. In this project, we will study ways in which the foveated rendering problem can be seen not as an image processing one but as a geometry processing one: can 3D assets themselves be given more or less level of detail depending on the focus of the user?
